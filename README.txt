Yu Su Kreativstudio 记账 App

部署到 GitHub Pages：
1. 新建 repository，例如 yusu-bookkeeping。
2. 上传 index.html、manifest.webmanifest、sw.js、icon.svg 到根目录。
3. Settings → Pages → Deploy from a branch → main / root。
4. 等待生成网址。
5. iPhone Safari 打开网址 → 分享 → 添加到主屏幕。

功能：
- 收入/支出/Privateinlage/Privatentnahme/Umbuchung
- 平台、支付方式、发票状态、现金入银行状态
- 搜索、筛选、日期范围、排序、编辑、删除
- 年/月统计、分类统计
- Excel(.xlsx)、CSV、JSON备份、打印/PDF
- JSON恢复备份
- 数据默认保存在当前设备浏览器本地

重要：建议每月导出 Excel 或 JSON 备份。
